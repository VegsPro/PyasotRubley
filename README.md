# PyasotRubley Launcher

Современный Android-лаунчер на **Jetpack Compose + Material 3** с **Glass UI** (Haze blur).

**applicationId:** `com.pyasotrubley.vegs`  
**Версия:** 1.0.0

## Возможности

- Рабочий стол с настраиваемой сеткой (3–6 колонок)
- App Drawer с поиском
- Док с быстрым доступом
- **Полная кастомизация**:
  - Glass-эффект (вкл/выкл)
  - Размер иконок и скругление
  - Показ названий и размер текста
  - Количество колонок / приложений в доке
  - Скрытие системных приложений
  - Свайп вверх → Drawer
- Тёмная тема по умолчанию
- Установка как лаунчер по умолчанию (через настройки)

## Сборка

### Локально
```bash
./gradlew assembleDebug
# или
./gradlew assembleRelease
```

### GitHub Actions
При пуше в `main` автоматически собираются Debug и Release APK (артефакты).

## Установка

1. Скачай APK из Actions → Artifacts
2. Разреши установку из неизвестных источников
3. Установи и **установи как лаунчер по умолчанию** (Настройки → Приложения → Лаунчер по умолчанию или кнопка в настройках приложения)
